# Документы проекта

Рабочие документы на русском языке. Описание проекта для всех — в [README.md](../README.md) в корне.

| Папка | Что лежит | Когда файл попадает сюда |
|---|---|---|
| [plans/](plans/) | Действующие планы и записи о том, что сделано и проверено | Идея одобрена и расписана как план к работе |
| [ideas/](ideas/) | Варианты улучшений на обсуждение | Идея предложена, но решения ещё нет |
| [archive/](archive/) | Отработанные и отклонённые планы и идеи | Работа закончена и больше не меняется, или идею решили не делать |

Как идея проходит путь:

1. Предложение записывается в `ideas/` со статусом «на обсуждении» (таблица в [ideas/README.md](ideas/README.md)).
2. После обсуждения у неё появляется решение: **делаем** → по ней пишется план в `plans/`; **позже** → остаётся в `ideas/`;
   **не делаем** → файл (или раздел) переносится в `archive/` с датой и причиной.
3. Выполненный план остаётся в `plans/`, пока к нему возвращаются; когда этап закрыт окончательно, план уходит в `archive/`.

Файлы переносятся командой `git mv`, поэтому история каждого сохраняется.
