## Общие принципы для всех режимов

- Режимы — надстройка над генератором, а не замена: свободный просмотр остаётся главным экраном, режимы включаются отдельно.
- Все новые тексты — в словарях `src/i18n.js` на трёх языках, с той же планкой качества перевода, что и сейчас.
- Каждый режим работает на телефоне: элементы режима встраиваются в существующие раскладки (лист, вкладки), а не поверх них.
- Без сервера: прогресс, альбомы и каталоги хранятся в браузере (`localStorage`, `IndexedDB`); делиться — ссылкой (Ф2).
- Ничего не должно стоить кадров в свободном режиме: код режимов не работает, пока режим выключен.
- Игры — собственные механики, без повторения существующих игр.
